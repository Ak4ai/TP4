Decisões de Engenharia

Arquitetura do Software

Separação de Responsabilidades e Estado persistente

O projeto divide-se claramente em módulos para manter as boas práticas de reuso de código e encapsulamento.

  • ⚙️
    Módulo Lógico (biblioteca.py) Encapsula as classes principais (`Biblioteca`, `Livro`, `Usuario`, `Emprestimo`) e regras de negócio essenciais.
  • 🖥️
    Módulo Visual (app.py) Desenvolve os componentes de tela, filtros interativos e consome APIs externas usando o framework Streamlit.
  • 💾
    Gerenciamento de Estado (State) Utiliza `st.session_state` para garantir que o objeto principal da Biblioteca permaneça persistente em memória entre os refreshes e interações da página.

Integração de Sistema (Digital)

O Servidor de Leitura Suwayomi

Gerenciador auto-hospedado de acervos digitais

O Suwayomi é uma ferramenta open-source que atua como um servidor local de mangás e quadrinhos (baseado no ecossistema Tachiyomi). Ele centraliza as fontes digitais e expõe dados através de uma API moderna.

  • 🔌
    Centralização de Catálogos Conecta com centenas de extensões de leitura online, unificando capítulos, capas e descrições em um único servidor local.
  • 🕸️
    API GraphQL Robusta Disponibiliza um endpoint local (`/graphql`) que permite recuperar dados complexos e aninhados em uma única chamada.
  • 🔄
    Sincronização com Trackers Permite integrar contas externas (como MyAnimeList e Anilist) para sincronizar status de leitura e avaliações globais.

Funcionalidade Livre (Destaque)

Integração de APIs Híbridas

Enriquecimento dinâmico de metadados

A integração de dados une as fontes físicas e digitais através de dois caminhos e protocolos inteiramente diferentes:

📚 OpenLibrary REST API (Físico)

Client-Side & REST (JSON): Executada diretamente no navegador do cliente via AJAX (`fetch`) no hover do título. Consulta a API pública em tempo real e exibe capas sem consumir banda do servidor.

🌐 Suwayomi GraphQL API (Digital)

Server-to-Server & GraphQL: Executada no backend Python (`requests`). O servidor consulta a API GraphQL local do Suwayomi para carregar status de leitura e capítulos e os cacheia em memória.

# --- 1. REST (JS Client Fetch) --- fetch(`https://openlibrary.org/search.json?q=${q}`) .then(res => res.json()) .then(data => { let doc = data.docs[0]; let img = `https://covers.openlibrary.org/...`; exibirCapa(img); });
# --- 2. GraphQL (Python Backend) --- def buscar_manga(manga_id): q = """ query GetManga($id: ID!) { manga(id: $id) { title status chapters { name } } } """ res = requests.post(url, json={"query": q, "variables": {"id": manga_id}}) return res.json()['data']['manga']
